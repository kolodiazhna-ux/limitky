Import fotiek zo Sheets

Nahraj JSON súbor vygenerovaný Apps Scriptom. Fotky sa automaticky priradia k produktom podľa kódu.

📋 Ako na to:

  1. Otvor svoju Google Tabuľku
  2. Klikni Extensions → Apps Script
  3. Vymaž všetok kód a vlož obsah súboru export-photos-script.gs
  4. Klikni ▶ Run → povoliť prístupy
  5. Stiahni vygenerovaný limitky-photos-export.json
  6. Nahraj ho tu dole 👇
